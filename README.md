# 剪切板助手

一款适用于 **macOS 14 及以上版本**的菜单栏应用，在本机记录剪切板历史，帮助你搜索、预览并将内容粘贴回前台应用。

应用没有 Dock 图标，启动后从屏幕顶部的菜单栏进入。当前分支支持本地历史、分组文本片段库，以及历史导入导出；不提供历史标签、自定义采集规则、同步、OCR、账号或自动更新。

## 主要功能

- 记录文本、富文本、图片和文件引用，约每 400ms 检查一次剪切板变化。
- 按内容、标题和来源应用名称搜索，按文本、图片、文件或置顶筛选。
- 预览历史、置顶常用条目、删除记录，并在访达中显示文件。每条历史显示来源应用图标、名称和相对时间；应用已卸掉或没有 bundle id 时显示通用应用符号。
- 按原始类型粘贴、粘贴纯文本，或仅复制到剪切板。
- 暂停采集、排除指定应用，按条数、天数和图片容量自动清理。
- 管理分组文本片段，支持关键词查找和 `{{name}}` 变量填写；可将完整文本历史保存为片段。
- 将历史导出为 JSON 备份或 TXT 文本，从 JSON 预览、去重并恢复历史。
- 设置开机启动、全局快捷键、外观、粘贴行为和面板位置。

## 从源码运行

需要 macOS 14 或更高版本，以及支持 macOS 14 SDK 的 Xcode。可直接用 Xcode 打开 `ClipboardAssistant.xcodeproj`，选择 `ClipboardAssistant` scheme 运行。

也可以在项目根目录执行：

```bash
xcodebuild -project ClipboardAssistant.xcodeproj -scheme ClipboardAssistant -destination 'platform=macOS' -derivedDataPath /tmp/ClipboardAssistantDD build
open /tmp/ClipboardAssistantDD/Build/Products/Debug/ClipboardAssistant.app
```

本地调试使用 ad-hoc 签名，不启用 App Sandbox。重新构建并替换正在运行的应用前，先结束旧的 `ClipboardAssistant` 进程。分发签名与公证说明见 [Packaging/notarize.md](Packaging/notarize.md)。

## 首次使用

1. 启动应用，在菜单栏找到剪切板图标。
2. 若需要自动粘贴，在「系统设置 → 隐私与安全性 → 辅助功能」中允许「剪切板助手」。未授权时菜单栏图标带圆点，点击图标会打开权限说明，可从中前往系统设置。此时仍可记录历史和复制内容。右键或按住 Control 点击图标仍可打开菜单。
3. 在其他应用中复制内容，稍后即可在历史中看到。
4. 按 **⌘⇧V** 打开主面板，搜索或选择一条记录，按回车粘贴回刚才的应用。

菜单栏菜单提供最近 10 条记录，以及「打开主面板」「暂停记录」和「设置」入口。

### 粘贴与复制

- **回车**：按原始类型粘贴；如果通用设置选择了「只写入剪切板」，则仅复制。
- **⌘回车**：仅复制，不自动粘贴。
- **⇧回车**：粘贴纯文本。
- **右键菜单 → 纯文本复制**：仅把纯文本写入剪切板。
- **⌫**：删除当前条。置顶条目先弹出确认框，确认后才删除。单条删除可用 ⌘Z 撤销，直到面板关闭。
- **⌘⌫**：清空全部历史。确认说明写明条数，并包含已置顶条目。取消不删除。没有记录时不弹窗；搜索框正在编辑时，这个快捷键仍用于清空。

自动粘贴失败时，面板会显示「未能自动粘贴，已复制，请手动粘贴」，此时可切回目标应用按 ⌘V。

打开主面板的全局快捷键默认为 ⌘⇧V，可在设置中修改，但不能使用单独的 ⌘C、⌘V、⌘X 或 ⌘Q。这个快捷键始终在鼠标光标所在屏幕的正中打开面板；菜单中的「打开主面板」遵循「面板位置」设置。暂停和恢复可以另外录制一组快捷键，默认不注册。

## 片段库

在主面板顶部切换到「片段」，可以新建、编辑、删除纯文本片段，并按分组整理。历史中的完整文本可通过「保存为片段」创建独立副本。

- 普通搜索在当前分组内匹配；输入 `;关键词` 可跨组精确匹配片段关键词，英文不区分大小写，确认后才复制或粘贴。
- 内容中使用 `{{name}}` 定义变量；使用片段时填写变量，确认预览后执行。变量填写内容不保存到片段库。
- 删除分组会将片段移到未分组，不删除片段内容。
- 清空历史和历史保留策略不影响片段。历史导入导出不包含片段库。

## 历史导入导出

历史面板底部提供「导出历史…」和「导入历史…」；「设置 → 存储」提供「导出全部历史…」和「导入历史…」。

### 导出备份

1. 在历史面板先搜索或筛选，再点击「导出历史…」。默认导出当前结果，也可切换为全部历史；设置页默认全部历史。
2. 选择格式：**JSON** 保留历史内容、支持的负载、来源、时间和置顶信息，可用于恢复；**TXT** 便于阅读，仅支持导出。
3. 选择保存位置。导出提供进度和取消；开始后新采集的记录不加入本次备份。

备份包含明文历史和本地路径，请自行保管。文件历史只保存引用，不复制原文件；超限历史仍是仅预览，备份不能恢复未保存的原文。备份不包含片段、设置或诊断数据。

### 从 JSON 恢复

1. 点击「导入历史…」，选择本应用支持的 JSON 备份。
2. 检查预览中的总数、文件内重复、本地重复、新增和保留策略淘汰数量；确认前不会修改历史。
3. 如果保留策略会淘汰原历史，需勾选确认后再导入。历史或保留设置发生变化时，需重新确认预览。
4. 查看结果中的实际写入、保留、重复跳过和淘汰数量。提交事务期间不可取消。

重复导入不会覆盖本地重复条目的内容、来源、时间或置顶状态。导入不写系统剪切板，也不打开或读取引用文件；文件移动或丢失后，其引用可能失效。格式、负载或资源校验失败会整批拒绝；写入失败会回滚。

归档文件上限为 **512 MiB**，解码负载与预览累计上限为 **256 MiB**，最多 **10,000 条**，单张图片最多 **40 MP**。预览负载目前保存在内存中，确认后写入临时区；接近上限的大备份性能仍待实机验收。超限时请缩小导出范围。

历史标签和规则设置已移除。旧数据库中的规则不再执行；旧标签仅作为旧备份元数据兼容，不显示、不参与搜索或筛选，也不为新记录分配标签。

## 隐私与本地数据

历史保存在本机目录：

```text
~/Library/Application Support/ClipboardAssistant/
```

默认隐私设置会跳过：

- 钥匙串访问、系统「密码」、1Password、1Password 7 和 Bitwarden 中的复制。
- 带机密标记或 `org.nspasteboard.TransientType` 标记的内容。
- 安全输入期间，以及安全输入结束后 1 秒内的剪切板变化。
- 暂停期间的变化，以及本应用自身写回的内容。

「设置 → 隐私」可管理排除应用、机密标记和安全输入选项，并显示当前是正在记录还是已暂停。菜单栏可暂停或恢复记录；暂停时长支持手动恢复、15 分钟和 1 小时。通用设置里可以给暂停另设一组全局快捷键。

日志及「设置 → 关于」导出的诊断 JSON 不包含剪切板正文。文件历史保存的是文件引用，不是文件内容备份。

## 保留策略与内容限制

默认最多保留 **500 条、30 天**，未置顶图片的容量上限为 **200MB**。

- 到期条目按创建时间清理；条数或图片容量超限时，优先清理最久未使用的未置顶条目。
- 置顶条目不参与条数、天数和图片容量限制。
- 设置中可调整条数与天数，也可选择不限制条数或永久保留；图片容量上限固定为 200MB。
- 单条文本超过 1MB 或图片超过 10MB 时，只保留预览信息，不能从该历史条目恢复复制或粘贴。
- 主面板 **⌘⌫** 和设置中的「清空全部历史」都会删除所有历史记录，**包括置顶条目**，但不删除片段库。

## 开发与测试

在项目根目录运行测试：

```bash
xcodebuild -project ClipboardAssistant.xcodeproj -scheme ClipboardAssistant -destination 'platform=macOS' -derivedDataPath /tmp/ClipboardAssistantDD test
```

单元测试位于 `Tests/`，不启动菜单栏应用。修改保留策略、哈希、隐私或粘贴模式时，需要补充对应断言。

历史导入导出的独立测试与行覆盖率检查：

```bash
bash scripts/test-history-transfer.sh

# 将结果目录替换为本次启用了代码覆盖率的 Xcode 测试结果
bash scripts/check-history-transfer-coverage.sh /path/to/Test.xcresult
```

获取覆盖率时，在全量测试命令中加入 `-enableCodeCoverage YES`；如指定 `-resultBundlePath`，应使用尚不存在的结果目录。覆盖率脚本检查 5 个归档模块文件，不代表整个应用或分支覆盖率。最近一次代码验证为全量 127 项通过，归档模块 1185/1185 行覆盖；详情与已知边界见 [验证记录](docs/rules-history-v1.1/validation.md)。

macOS 14 实机、VoiceOver 全流程和大备份性能尚未全部验收，自动化测试通过不能替代这些检查。

### 目录导航

- `App/`：应用入口、菜单栏和面板装配。
- `Domain/`：条目模型、哈希、搜索和保留策略。
- `Features/`：采集、历史面板、导入导出、片段库、粘贴、隐私和设置。
- `Storage/`：SQLite 数据库与负载文件。
- `Platform/`：全局热键、辅助功能、登录项和前台应用。
- `Tests/`：逻辑与存储测试。
- `Packaging/`：分发签名与公证说明。
