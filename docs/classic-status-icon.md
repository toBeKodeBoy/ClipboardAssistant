# 01 经典剪贴板菜单栏图标

## 技术方案

复用 `StatusIcon.image(paused:trusted:)`，使用 AppKit 的 `NSBezierPath` 绘制，替代系统 clipboard 符号。不引入图片依赖或新的 Swift 文件，保持工程编译列表不变。

- 逻辑画布 18 × 18 pt，透明背景；`isTemplate = true`，前景色交给 macOS，适配浅色和深色菜单栏。
- 圆角剪贴板外框、顶部圆角夹子、两条不同长度的文字线；主要线宽 1.6 pt。
- 暂停时绘制左下至右上的斜杠；未授权时右下角绘制圆点，透明间隙隔开外框。两种标记可以同时存在。
- 使用按需绘制的 NSImage，在系统请求的分辨率下绘制路径，支持 Retina。
- 保留暂停回调、权限轮询和菜单打开时刷新图标的现有调用方式，保留全部点击行为。

## TDD 与验收范围

先添加 `testClassicStatusIconPixelsAtBothScales`，在旧实现上运行：1 个用例、22 项断言失败。随后实现路径绘制。首次全量测试发现圆点探针命中外框，修正为外框之外、圆点内部的位置。

测试遍历暂停与授权的四种组合，并在 1× 和 2× 位图上实际触发绘制，断言模板属性、尺寸、两条文字线、透明边距、中央斜杠及右下角圆点。原有控制器测试继续验证状态切换及权限菜单行为。
