# Mac 剪切板助手 · 产品需求文档

| 项 | 内容 |
|---|---|
| 产品名 | 剪切板助手（暂定） |
| 平台 | macOS 14 Sonoma 及以上，Apple Silicon 与 Intel 通用 |
| 形态 | 菜单栏常驻应用，无 Dock 图标 |
| 版本目标 | v1.0 本地历史；v1.1 片段与规则；v2.0 同步 |
| 分发 | 公证后的直接下载；App Store 作为后续渠道 |

## 1. 背景与目标

系统剪切板只保留最近一次复制。写代码、写文档、客服回复时，上一条内容经常被覆盖，用户只能重新复制。

本产品在本地记录复制历史，用快捷键召回并粘贴回当前应用，减少来回切换。

**成功标准（上线 4 周）**

- 安装后 1 分钟内完成授权并记下第一条历史。
- 从呼出面板到粘贴完成，常用路径不超过 2 次按键（快捷键 + 回车）。
- 连续复制 200 条后，搜索第一条仍能在 200ms 内出结果（本机 SSD、纯文本）。
- 密码框、排除应用中的复制不进入历史。

## 2. 用户与场景

| 用户 | 典型场景 |
|---|---|
| 开发者 | 在终端、编辑器、浏览器之间搬运命令、报错、链接 |
| 写作者 / 运营 | 反复使用固定话术、标题、链接 |
| 设计 / 支持 | 找回刚才复制的图片、文件路径、工单号 |

**主路径**

1. 用户在任意应用里复制文本、图片或文件。
2. 助手在后台记下一条历史，菜单栏不打断当前工作。
3. 用户按下全局快捷键，面板出现在光标或屏幕中心附近。
4. 方向键或搜索选中一条，回车后内容写入剪切板并粘贴到当前应用。
5. 面板关闭，焦点回到原来的输入位置。

## 3. 范围

**v1.0 做**

- 文本、富文本、链接、图片、文件的历史记录
- 搜索、预览、置顶、删除、清空
- 一键粘贴到前台应用，以及「只复制不粘贴」
- 纯文本粘贴
- 隐私排除（密码输入、指定应用、临时暂停）
- 容量与保留策略
- 菜单栏、全局快捷键、开机启动、偏好设置

**v1.0 不做**

- 账号、云同步、团队共享
- OCR、翻译、AI 改写
- iOS / iPad 客户端
- 片段库（Snippets）的变量与表单（放到 v1.1）
- 跨设备 Universal Clipboard 的增强（只避免和系统行为打架）

## 4. 信息架构

```text
菜单栏图标
├── 最近 10 条（点一条即粘贴）
├── 打开主面板          ⌘⇧V（可改）
├── 暂停记录
└── 设置…

主面板
├── 搜索框
├── 筛选：全部 / 文本 / 图片 / 文件 / 置顶
├── 列表（时间分组：刚刚、今天、昨天、更早）
└── 预览区（宽面板时在右侧，窄面板时在列表下方）

设置
├── 通用（开机启动、快捷键、外观、粘贴行为）
├── 隐私（排除应用、忽略机密、暂停）
├── 存储（条数、天数、图片大小、清空）
└── 关于（版本、权限状态、导出诊断）
```

面板默认宽度约 640px，高度约 480px。可拖拽边缘记忆尺寸。支持深色模式和跟随系统。

## 5. 功能需求

### 5.1 采集

| 编号 | 需求 | 验收 |
|---|---|---|
| C1 | 监听系统通用剪切板变化，新内容入库 | 在「文本编辑」、Safari、Terminal、Finder 中复制后，2 秒内出现在历史顶部 |
| C2 | 同一内容连续复制不产生重复记录；再次复制旧内容时，把该条移到顶部并更新时间 | 连续按三次复制，历史仍只有 1 条且时间为最后一次 |
| C3 | 支持纯文本、RTF、HTML、URL、PNG/TIFF/JPEG、文件 URL | 各类型均能预览并原样粘回原应用 |
| C4 | 单条纯文本上限 1MB；图片单条上限默认 10MB，超出只存类型标记和「内容过大未保存」 | 超限条目可见，粘贴时提示未保存 |
| C5 | 自身写入剪切板（用户选中历史并粘贴）不得再记成一条新历史 | 粘贴后历史条数不变 |
| C6 | 检测到安全输入（密码框）时跳过本次采集 | 在 1Password、系统登录框、Safari 密码框中复制，历史不增加 |
| C7 | 提供「暂停记录」；暂停期间不采集，已有历史仍可粘贴 | 菜单栏图标变为暂停态，恢复后新复制重新入库 |

去重键：文本用规范化后的 UTF-8 内容哈希；图片用像素数据哈希；文件用路径列表加文件大小与修改时间。富文本同时保存纯文本，搜索走纯文本。

### 5.2 浏览、搜索、预览

| 编号 | 需求 | 验收 |
|---|---|---|
| B1 | 主面板列出历史，新的在上，按时间分组 | 分组标题正确，置顶区固定在最上方 |
| B2 | 搜索匹配纯文本、来源应用名、文件名；中文按包含匹配，英文不区分大小写 | 输入「错误」能命中包含该词的条目；输入文件名能命中文件条目 |
| B3 | 搜索在本地增量过滤，200 条纯文本结果出现时间 < 200ms | 本机实测达标 |
| B4 | 文本预览保留换行，超长截断并可滚动；图片显示缩略图；文件显示图标、名称、数量 | 多文件复制显示「N 个文件」 |
| B5 | 每条展示来源应用图标与名称、相对时间 | 来源取复制发生时的前台应用 |
| B6 | 空历史显示引导：如何复制、当前快捷键、权限是否缺失 | 首次启动可见 |

### 5.3 粘贴与编辑

| 编号 | 需求 | 验收 |
|---|---|---|
| P1 | 回车：把该条写回剪切板，并向当前前台应用发送粘贴（⌘V） | 焦点仍在原输入框，内容被粘贴 |
| P2 | ⌘回车：只写入剪切板，不粘贴，面板关闭 | 随后手动 ⌘V 得到该内容 |
| P3 | ⇧回车：以纯文本粘贴，去掉字体、颜色、链接样式 | 从网页复制的富文本以纯文本进入「文本编辑」 |
| P4 | ⌫ 删除选中条；⌘⌫ 清空全部，需二次确认 | 确认文案写明条数，取消不删除 |
| P5 | ⌘P 或右键「置顶 / 取消置顶」；置顶不参与条数淘汰 | 达到上限时先淘汰未置顶的旧记录 |
| P6 | 右键可复制、纯文本复制、在访达中显示（仅文件）、删除 | 文件已被移动或删除时提示无法显示 |
| P7 | 双击等价于回车粘贴 | 与键盘路径结果一致 |
| P8 | Esc 或点击面板外关闭，不改变剪切板 | 关闭后面板不再接收按键 |

粘贴实现要求：先激活原来的前台应用，再写入剪切板，再发送 ⌘V。粘贴失败时保留剪切板内容，并在面板底部提示「未能自动粘贴，已复制，请手动粘贴」。

### 5.4 快捷键与菜单栏

| 编号 | 需求 | 默认 | 验收 |
|---|---|---|---|
| K1 | 打开主面板 | ⌘⇧V | 在任意普通应用中可呼出；与系统或其他应用冲突时，设置页标红并允许重设 |
| K2 | 菜单栏最近列表 | 点击图标 | 展示最近 10 条，点击即粘贴 |
| K3 | 暂停 / 恢复 | 无默认全局键，可自选 | 状态在图标和设置中一致 |
| K4 | 快捷键录制 | — | 支持修饰键 + 主键；不允许单独使用 ⌘C / ⌘V / ⌘X / ⌘Q |

快捷键通过系统热键 API 注册。录制时先注销旧热键，保存成功后再注册新热键。

### 5.5 隐私与排除

| 编号 | 需求 | 验收 |
|---|---|---|
| S1 | 排除应用列表：按应用添加，命中时不采集 | 将「密码」类应用加入后，从其窗口复制不入库 |
| S2 | 默认排除建议：钥匙串访问、1Password、Bitwarden 等常见密码管理器，用户可删 | 首次启动预填，可移除 |
| S3 | 「忽略机密标记」默认开启：剪切板带 concealed / org.nspasteboard.ConcealedType 时不采集 | 密码管理器复制密码不入库 |
| S4 | 设置中可一键清空全部历史，清空后数据库真空回收 | 清空后重启仍为空 |
| S5 | 历史只存本机应用支持目录，不上传 | 无网络权限需求；抓包无业务请求 |
| S6 | 暂停可设定时长：手动恢复、15 分钟、1 小时 | 到时自动恢复并更新图标 |

### 5.6 存储与保留

| 编号 | 需求 | 默认 |
|---|---|---|
| R1 | 最多保留条数 | 500，可选 200 / 500 / 1000 / 不限制 |
| R2 | 最长保留天数 | 30，可选 7 / 30 / 90 / 永久 |
| R3 | 图片总容量上限 | 200MB，超出删最旧的未置顶图片 |
| R4 | 置顶不计入自动淘汰 | — |
| R5 | 应用退出与系统重启后历史仍在 | 进程被杀后数据不丢 |

存储建议：元数据用 SQLite，图片与文件快照用独立文件，以内容哈希命名。列表查询只读元数据和缩略图，预览大图时再读原文件。

### 5.7 设置与系统集成

| 编号 | 需求 | 验收 |
|---|---|---|
| G1 | 开机启动，默认关闭 | 打开后注销再登录，进程自动起来且不显示 Dock 图标 |
| G2 | 外观：跟随系统 / 浅色 / 深色 | 切换后面板立即生效 |
| G3 | 粘贴行为：自动粘贴（默认）或只复制 | 设置立即生效，无需重启 |
| G4 | 面板出现位置：鼠标附近（默认）或屏幕中心 | 靠近屏幕边缘时面板完整落在可见区域内 |
| G5 | 权限引导页说明「辅助功能」用途，并提供跳转到系统设置的按钮 | 未授权时粘贴按钮可用，自动粘贴给出明确原因 |
| G6 | 检查更新（直接分发版本） | 可关闭；不自动下载安装 |

## 6. 权限与系统行为

| 权限 | 是否必需 | 用途 |
|---|---|---|
| 辅助功能 | 自动粘贴必需；采集历史不需要 | 向原应用发送 ⌘V，读取前台应用身份 |
| 输入监控 | 不申请 | 不用来监听键盘内容 |
| 屏幕录制 | 不申请 | v1 不做截图 OCR |
| 完全磁盘访问 | 不申请 | 只记录用户已复制到剪切板的文件 URL，不主动扫描磁盘 |

**安全输入：** 系统处于 Secure Input 时停止采集，避免在密码场景留下记录。

**与系统通用剪贴板的关系：** 不拦截、不关闭 Handoff 通用剪贴板。从其他苹果设备同步来的内容，按普通新剪切板处理，来源显示为「通用剪贴板」或实际前台应用。

**沙盒：** 直接分发版可不沙盒，以便稳定枚举前台应用和发送粘贴。若上 App Store，需改为沙盒加辅助功能用途字符串，并复测文件粘贴与应用排除。

## 7. 数据要点

每条历史至少包含：

- 标识、类型（文本 / 富文本 / 图片 / 文件 / 混合）
- 纯文本摘要（列表和搜索用）
- 原始剪切板类型及负载位置
- 来源应用 bundle id、应用名
- 创建时间、最近使用时间
- 置顶标记、置顶顺序
- 内容哈希（去重）
- 字节大小；图片宽高

删除条目前先删负载文件，再删数据库行。清空使用事务。

## 8. 交互细则

- 面板打开时搜索框自动聚焦，列表选中第一条。
- ↑ ↓ 移动选中；⌘1–⌘9 粘贴当前筛选结果的前 9 条。
- 按键预览在面板底部常驻：回车粘贴、⌘回车复制、⇧回车纯文本、⌫ 删除。
- 菜单栏图标：正常为单色模板图标；暂停时加斜杠；权限缺失时加圆点，点击后进入权限说明。
- 所有破坏性操作（清空、删除置顶）都要确认。单条删除不确认，并支持 ⌘Z 在面板内撤销最近一次删除，保留到面板关闭。

## 9. 非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | 常驻内存目标 < 80MB（500 条文本 + 50 张缩略图）；采集不造成前台输入卡顿 |
| 可靠 | 崩溃后重启可恢复数据库；写入使用 WAL |
| 隐私 | 日志不记录剪切板正文；诊断导出只含版本、权限、条数统计 |
| 本地化 | v1 简体中文与英文；时间用相对时间 |
| 兼容 | 覆盖 Safari、Chrome、微信、飞书、Terminal、iTerm、VS Code、Finder、文本编辑、备忘录、Word |
| 安装 | Developer ID 签名并公证；支持拖入「应用程序」文件夹 |

## 10. 版本切片

**v1.0 里程碑**

1. 菜单栏 + 采集文本 / 图片 / 文件
2. 面板搜索、预览、粘贴、纯文本粘贴
3. 置顶、删除、清空、保留策略
4. 排除应用、机密标记、安全输入、暂停
5. 设置、开机启动、权限引导、公证包

**v1.1**

- 片段库：手动保存、分组、关键字触发
- 规则：按来源应用自动打标签、正则忽略（如验证码样式可配置，默认不忽略）
- 历史导出为 JSON 或纯文本，导入时去重

**v2.0**

- 可选 iCloud 同步，端到端加密，不同步排除应用中的内容
- 设备间冲突以「最近使用时间」为准

## 11. 验收用例（发布前必过）

1. 复制 3 段不同文本，呼出面板，选中第 2 条回车，当前文本框出现第 2 条。
2. 从网页复制带链接的标题，⇧回车后目标应用得到无格式文本。
3. 在 Finder 复制 2 个文件，从面板粘贴到桌面，得到同样的 2 个文件（复制粘贴语义，不移动原文件）。
4. 复制一张截图，历史出现缩略图，粘贴到备忘录后图片可见。
5. 在密码框复制，历史条数不变。
6. 将终端加入排除列表后，终端里的复制不入库；从面板仍可把旧历史粘贴进终端。
7. 条数上限调到 200，制造 201 条非置顶记录，最旧一条消失，置顶条仍在。
8. 未授予辅助功能时，历史正常记录，自动粘贴有提示，⌘回车仍能复制。
9. 强制退出进程后重开，历史、置顶、设置都在。
10. 快捷键与其他应用冲突时可以改键，改完旧键失效、新键生效。

## 12. 风险

| 风险 | 处理 |
|---|---|
| 部分应用忽略模拟的 ⌘V | 失败提示改为手动粘贴；对已知应用在发布说明中列出 |
| 安全输入误伤正常采集 | 设置中提供「安全输入时仍记录」开关，默认关闭，文案说明风险 |
| 大图片拖慢列表 | 只显示缩略图，原图异步落盘 |
| App Store 审核对辅助功能敏感 | v1 走公证直接分发，商店版单独评估 |
| 通用剪贴板把手机内容同步进来 | 正常入库，来源标注清楚，用户可删除 |

---

v1.0 的边界是：本地、可搜索、可粘贴、默认可信的复制历史。片段库和同步不进入第一版，避免权限和加密把首发拖长。
