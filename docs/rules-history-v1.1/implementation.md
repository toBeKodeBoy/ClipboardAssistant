以下记录补充并取代上文“必须继续的工作”中对应的旧状态；上文保留为开发历史。

- 已接入设置“规则”页、应用标签与正则规则编辑/启停/删除确认、空匹配确认、内存内测试文本与测试结果；保存失败保留输入。
- 新采集使用规则版本快照；标签仅在首次插入时保存，重复采集不覆盖。历史显示标签，提供全部/无标签/指定标签筛选，标签参与普通搜索，与类型筛选取交集。NFC 和大小写折叠用于标签比较。

- 正则在应用二进制的独立 worker 进程执行，进入 worker 时不创建 NSApplication 或菜单栏。一次最多 50 条、输入 8 MiB、单表达式 4096 字节、默认执行预算 100 ms；超时 SIGKILL 并等待进程退出。文本任务只允许一个在途，繁忙变化直接拒绝；异常期间拒绝后续文本，修复/禁用/删除规则并成功保存后恢复，无文本变化仍可采集。
- HTML 提取采用本地保守提取器，不使用可能访问网络的 HTML 渲染器；不支持或有歧义的实体、原始文本元素等输入拒绝采集并提示，不能静默放行。这并非通用浏览器 HTML 渲染实现。常见同时携带纯文本的剪切板只检查纯文本表示。
- 已按本次明确授权迁移至数据库 v4：新增文件引用元数据、导入批次、待清理记录及历史修订计数。保留既有 items 表与数据、片段和规则；未来数据库版本拒绝打开。WAL 使用 FULL 同步。
- 已接入历史面板和设置存储页的 JSON/TXT 导出、JSON 选择/校验/预览/确认/结果。文件选择取消无历史修改，导入表单期间不路由历史删除和粘贴快捷键。结果分别列出新增候选、实际写入并保留、重复和策略淘汰数量。
- 导出固定元数据快照并为负载持有读取租约；删除、清空和导入淘汰均保护租约。逐条编码到目标目录临时文件，完成同步后原子替换，支持进度和取消，不改变历史时间。
- 导入逐条解析 JSON，拒绝重复字段、未知字段/类型、非法负载和路径、格式版本错误。文件上限 512 MiB、解码负载与预览累计 256 MiB、元数据累计 16 MiB、最多 10000 条；图片实际解码验证、尺寸一致且最多 40 MP。日期兼容旧 ISO 8601，并保留 SQLite 时间戳的小数精度。
- 预览不写历史。重算现有内容哈希，独立预览标识与完整条目隔离；同文件保留首条，本地重复不更新元数据。置顶追加到末尾且保留策略豁免。提交前校验历史修订和保留计划；影响原历史必须勾选确认，失效重新预览并重置确认。
- 负载先写同卷 staging 并同步，再移动到本机 UUID 目录；批量插入、淘汰及清理记录在单个 SQLite 事务提交。失败回滚并仅清理本批文件；提交后才清理淘汰负载。启动回收未提交 staging、孤立负载和待清理记录。导入图片生成缩略图。
- 文件引用不会 stat 或读取原文件。旧版历史未保存文件属性，导出显式标记 legacyFileMetadata，保留路径及既有字节统计；缺失属性不冒充已知原值。本地旧文件记录额外用路径快照识别重复。

### 实现与原拟议方案的差异

采用可终止的独立进程 worker，而非另建 XPC target；已用复杂表达式实测终止和随后正常请求。解析每次仅缓冲一条 JSON 记录，解码后的预览负载在内存中累计，硬上限 256 MiB；确认提交时才写 staging。这避免同时保留整个 Base64 文件和整个解码副本，但尚未实现原方案“校验阶段即将全部负载落到临时区”的更低常驻内存方式。未把这一差异表述为已实现。

### 验证口径

验收覆盖率为本次约定的新增规则与导入导出模块 **Xcode 行覆盖率**，具体 8 个文件由 `scripts/check-rules-coverage.sh` 显式列出；不等于整个应用 100%，也不等于分支覆盖率或全部人工验收通过。未排除其中的 UI 状态、错误恢复或 worker 代码。

自动化用例包含规则输入/编辑/失败恢复、完整文本与隐私/版本检查、标签快照与筛选、JSON 多条往返/非法输入/重复字段、时间精度、图片和文件引用、导入去重/保留/并发失效、磁盘写失败/SQLite 失败回滚、导出取消/租约以及真正子进程在写文件、移动、提交前、提交后直接退出后的重启恢复。

最终结果和可复现命令见 `validation.md`。测试使用合成文本和临时目录，没有在测试报告中保存用户剪切板正文。尚未完成 macOS 14 实机、VoiceOver 全流程和大备份峰值内存/吞吐量的人工验收。

最终收尾：规则测试文本关闭时立即使旧回调失效，并在下一轮主线程事件清空显示状态；确认框的框架回写也延迟到更新结束后，消除了新增规则页的 SwiftUI 更新警告。导出进度仅刷新传输视图，主模型仅转发传输表单的显示状态，避免反复刷新整个历史面板。最终全量测试为 145 项通过，新增 8 个模块文件 1689/1689 可执行行覆盖，见 `validation.md`。
