# v1.1 片段库实现与验证记录

日期：2026-11-10。分支：`feat/snippet-library`，基于最新 `origin/main`（3faba96）。本次为片段库开发分支，不是完整 v1.1 发布。

## 已接入的行为

- 历史/片段切换；新建、编辑、删除纯文本片段；完整文本历史保存为独立片段。
- 单层分组创建、重命名、删除与移动；删除组保留内容，历史清空与保留策略不影响片段。
- 普通搜索在当前分组内匹配；`;keyword` 忽略英文大小写、跨组精确匹配，确认后才执行。
- `{{name}}` 变量去重、标签、必填/选填、单行/多行表单及展开预览。
- 字节限额、非递归替换、转义、非法模板拒绝；变量值不落库、不进诊断，关闭或取消即释放会话引用。
- 复制/粘贴复用现有自身写入抑制与粘贴模式；目标失效或切换后拒绝发送按键，保留已复制内容及失败表单。
- SQLite 新增片段与分组表，事务升级到 user_version=2；拒绝未知新版本；原历史表和主键不变。

## 检查中修复的问题

- 升级后历史库启动代码原本会固定写回版本 1；改为保留已升级版本并拒绝未知版本。
- 片段使用时检查修订和目标应用；激活失败、目标在发送前切换或权限撤回时不发送按键。
- 删除确认动作捕获条目/分组身份，避免系统先关闭确认框导致删不到或删错对象。
- 分组编辑改为面板内表单，存储失败保留输入，允许重试。
- 片段页、编辑器及填写表单不路由到历史清空；非激活面板中的文本编辑快捷键继续发送给当前文本控件。
- 历史加载失败保留最后成功列表并提示，不再用空列表掩盖数据库异常。
- 全局“只复制”偏好在表单开始时解析成实际动作，执行按钮显示只复制。
