# 剪切板助手 · 功能清单 v1.2

| 项 | 内容 |
|---|---|
| 对照 | `docs/requirements.md` 第 10 节、第 13 节 |
| 范围 | 原先标成未排期、现归 v1.2 的能力 |
| 状态 | 未做。代码里没有这些能力 |

翻译、AI 改写、Agent 工具调用、Windows、Linux、移动端，以及绕过其他软件的剪切板防读取，仍然不纳入。入口、算法和交互细节需求没写的，不在这里补。

## 1. 列表与类型

| 功能 | 状态 | 需求写了什么 |
|---|---|---|
| 颜色类型 | 未做 | 历史增加颜色。v1.0 的类型没有颜色 |
| 列表分页 | 未做 | 列表现在一次载入。分页方式没写 |

## 2. 分类、标签与收藏

| 功能 | 状态 | 需求写了什么 |
|---|---|---|
| 自动分类 | 未做 | 链接、代码、手机号、银行卡。图片和文件仍用现有类型 |
| 自定义标签 | 未做 | 用户自己打标签。和 v1.1 按来源应用自动打标签不是一回事 |
| 收藏夹 | 未做 | 单独的收藏。v1.0 的置顶保留 |

## 3. 内容转换

| 功能 | 状态 | 需求写了什么 |
|---|---|---|
| 去换行、去空格 | 未做 | 对文本做转换。作用在粘贴、复制还是新条目上，没写 |
| URL 编解码、Base64 | 未做 | 同上 |
| JSON 格式化、大小写 | 未做 | 同上 |
| 文本转二维码 | 未做 | 同上 |
| 保留代码缩进 | 未做 | 同上。v1.0 的纯文本粘贴仍然保留 |

## 4. 批量

| 功能 | 状态 | 需求写了什么 |
|---|---|---|
| 批量复制、批量导出、批量删除 | 未做 | 一次处理多条。选择方式和确认方式没写 |
| 合并多条文本 | 未做 | 把多条文本合成一条。分隔方式没写 |

单条删除和清空全部仍按 v1.0。

## 5. 规则动作与敏感内容

| 功能 | 状态 | 需求写了什么 |
|---|---|---|
| 复制链接后自动打开 | 未做 | 命中链接后打开。用哪个应用打开，没写 |
| 复制报错后交给分析 | 未做 | 只记这个动作。分析不使用翻译、AI 改写或 Agent 工具 |
| 预置敏感规则 | 未做 | 识别密码、密钥、token、身份证，然后跳过、脱敏或单独擦除。v1.1 的正则忽略仍由用户配置，默认关闭 |
| 只监听指定软件 | 未做 | 与现有排除应用并存。排除应用仍是点名后不采集 |

## 6. 预览、导出、外观与加密

| 功能 | 状态 | 需求写了什么 |
|---|---|---|
| JSON 树形预览 | 未做 | 在现有文本预览之外 |
| 代码语法高亮 | 未做 | 同上 |
| 导出 Markdown、CSV | 未做 | v1.1 的导出仍是 JSON 或纯文本 |
| 自动备份历史 | 未做 | 备份位置和频率没写 |
| 额外主题 | 未做 | 跟随系统、浅色、深色之外再加主题。这三档保留 |
| 数据库加密 | 未做 | 含解锁口令，以及内存中敏感内容定时清理。口令如何保存，没写 |
