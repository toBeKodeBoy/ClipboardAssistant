# 剪切板助手 · 功能清单

| 项 | 内容 |
|---|---|
| 对照 | 当前代码。需求见 `docs/requirements.md`，设计见 `docs/technical-design.md` |
| 范围 | v1 本地历史。状态以代码为准 |
| 状态 | 已实现 / 部分实现 / 未做 |

界面文案通过 `L10n.text(zh:en:)` 提供简体中文和英文。应用是 macOS 14 菜单栏程序，`LSUIElement = YES`，无 Dock 图标，不开启 App Sandbox。

## 1. 采集

每 400ms 在主线程看一次系统剪切板 `changeCount`。解码、哈希和建条目在串行队列上做，完成后再回到主线程入库。启动时记下当前 `changeCount`，不会把启动前已在剪切板上的内容再记一条。

| 功能 | 状态 | 实现要点 |
|---|---|---|
| 记录纯文本、UTF-16、RTF、HTML、URL | 已实现 | 只读这些类型，粘贴时按原类型写回 |
| 记录 PNG、TIFF、JPEG | 已实现 | 入库时生成长边 360 像素的 JPEG 缩略图；解码失败不影响条目入库 |
| 记录一个或多个文件 | 已实现 | 只存路径、文件名、大小和修改时间，不备份文件内容 |
| 混合内容 | 已实现 | 图片和文件同时存在时记为 `mixed`。富文本配图片记为图片，富文本配文件记为文件 |
| 连续复制去重 | 已实现 | 相同内容哈希只更新 `last_used_at` 并移到顶部，不新增一行 |
| 文本哈希 | 已实现 | NFC，换行统一为 `\n`，再做 SHA-256。不裁剪首尾空白 |
| 图片哈希 | 已实现 | 优先用像素数据；能画成同一套 RGBA8 时，PNG 与 TIFF 像素相同则视为同一张图 |
| 文件哈希 | 已实现 | 路径按字典序拼接，加上每个文件的大小和修改时间 |
| 超限内容 | 已实现 | 单条文本超过 1MB，或图片超过 10MB：先对原文哈希，再只留预览。不同的大文本不会并成一条。这条不能再复制或粘贴 |
| 自身写入不入库 | 已实现 | 写回前记下哈希和负载摘要。随后 1 秒内，同一 `changeCount` 或仍含这些摘要的变化都跳过。前台就是本应用时也跳过 |
| 来源应用 | 已实现 | 取变化发生时的前台应用。带通用剪贴板远程标记时，名称写「通用剪贴板」，图标仍用当时的前台应用 |
| 不拦截系统通用剪贴板 | 已实现 | 不关闭 Handoff。从其他苹果设备同步来的内容按普通新记录处理 |

| 搜索 | 已实现 | 匹配纯文本、标题和来源应用名。去掉首尾空白后做包含匹配，英文不区分大小写 |
| 筛选 | 已实现 | 全部 / 文本（含富文本）/ 图片 / 文件（含混合）/ 置顶。筛选先于搜索 |
| 来源图标 | 已实现 | 按 bundle id 查已安装应用并缓存。为空或应用已不存在时用通用应用符号。菜单栏最近 10 条不显示图标 |
| 文本预览 | 已实现 | 保留换行，可滚动，可选中文本 |
| 图片预览 | 已实现 | 显示缩略图 |
| 文件预览 | 已实现 | 多个文件的标题为「首个文件名 等 N 个文件」 |
| 窄面板布局 | 已实现 | 默认 640×480，最小 420×360。宽度小于 720 时预览在列表下方，达到 720 后回到右侧。尺寸在关闭时记住 |

## 3. 粘贴、复制与删除

打开面板或菜单时立刻记下当时的前台应用，作为这次粘贴目标。粘贴按键前先关闭面板。失败时重新打开面板，保留原目标和提示。关闭面板不修改剪切板。

| 操作 | 状态 | 行为 |
|---|---|---|
| 回车、双击、⌘1–⌘9 | 已实现 | 按原始类型写回，并发送 ⌘V。⌘1–⌘9 作用于当前筛选结果的前 9 条 |
| ⌘回车、右键「复制」 | 已实现 | 只写入剪切板 |
| ⇧回车 | 已实现 | 只写纯文本，并发送 ⌘V |
| 右键「纯文本复制」 | 已实现 | 只写纯文本，不发送按键 |
| 菜单栏最近一条 | 已实现 | 按原始类型粘贴。菜单最多 10 条，点击即粘贴 |
| 通用设置「只写入剪切板」 | 已实现 | 只改回车这条路径。⌘回车、⇧回车和纯文本复制仍按各自的模式 |
| 未授权或按键失败 | 已实现 | 剪切板已经写好，面板显示「未能自动粘贴，已复制，请手动粘贴」 |
| 超限条目 | 已实现 | 不改剪切板，提示「内容过大未保存」 |
| 文件粘贴 | 已实现 | 把文件 URL 放回剪切板，由目标应用执行复制，不移动原文件 |
| ⌫ / 右键删除 | 已实现 | 删除当前条。置顶先确认，确认后删除打开确认框时记下的那一条，不跟随后来的选中变化 |
| ⌘Z | 已实现 | 可撤销最近一次单条删除。状态只留在内存里。清空或关闭面板会丢掉这次撤销。搜索框正在编辑时，⌘Z 改为撤销输入，⌘⇧Z 重做 |
| ⌘P、预览区按钮、右键 | 已实现 | 置顶或取消置顶 |
| 在访达中显示 | 已实现 | 仅文件和混合条目。路径已失效时提示「无法在访达中显示」 |
| ⌘⌫、设置里的清空 | 已实现 | 二次确认，文案写明条数并说明包含置顶。历史为空时不弹窗。搜索框正在编辑时 ⌘⌫ 仍清空。取消或关闭面板都不删除 |
| 删除或清空失败 | 已实现 | 提示「删除失败」或「清空失败」，列表不显示成已删除。历史随后变为空时，清空失败提示消失 |

搜索框正在编辑时，Delete、左右方向键、Home、End 交给输入框。⌘A 全选，⌘C 复制，⌘V 粘贴，⌘X 剪切，⌘Z 撤销输入，⌘⇧Z 重做。面板不激活应用，这些组合键由面板直接发给输入框。回车仍粘贴当前条目。

## 4. 菜单栏与快捷键

| 功能 | 状态 | 实现要点 |
|---|---|---|
| 菜单栏常驻 | 已实现 | 模板图标。暂停加斜杠，辅助功能未授权加圆点。暂停状态变化时立刻重画，不等到下次打开菜单 |
| 菜单内容 | 已实现 | 最近 10 条、打开主面板、暂停或恢复、设置、退出。没有历史时显示不可点的「暂无记录」。暂停热键已设置且注册成功时，菜单项后面带上该组合。冲突或注册失败时不显示组合。菜单「退出」和 ⌘Q 都结束进程，历史仍留在本机。⌘Q 在主面板、设置、权限说明或状态栏菜单打开时生效，不注册成全局热键，其他应用的 ⌘Q 不变 |
| 打开主面板 | 已实现 | 默认 ⌘⇧V。全局快捷键始终在光标所在屏幕正中打开；菜单「打开主面板」才跟随「面板位置」（鼠标附近或屏幕中心）。靠近边缘时限制在该屏幕可见区域内 |
| 快捷键录制 | 已实现 | Carbon 修饰键加一个主键。拒绝单独的 ⌘C、⌘V、⌘X、⌘Q，也拒绝和另一组相同的组合。注册失败时设置页把对应快捷键标红，原来已生效的热键保持可用 |
| 暂停的全局快捷键 | 已实现 | 默认不注册。通用设置里可以录制，也可以清除。按下后按暂停时长暂停或立即恢复。菜单里的「暂停记录」仍然可用 |
| 未授权时点击图标 | 已实现 | 图标加圆点。左键在鼠标抬起后打开权限说明，不打开普通菜单。说明页写明辅助功能用于发送 ⌘V，历史和只复制仍可用，高度随内容变化，超出屏幕时可滚动。提供「打开系统设置」（先激活应用，再弹出系统授权提示，并打开辅助功能页）和「打开主面板」。右键或按住 Control 点击仍打开原来的菜单。授权后左键恢复为普通菜单，圆点消失。空历史和关于页仍可打开系统设置 |
| Esc、点击面板外 | 已实现 | 只关闭面板。未确认的清空和删除置顶一并取消 |

## 5. 隐私

跳过规则集中在 `PrivacyGate`。返回 false 即跳过，采集处不再复制一套判断。

| 功能 | 状态 | 实现要点 |
|---|---|---|
| 暂停记录 | 已实现 | 暂停期间不采集，已有历史仍可粘贴。时长为手动恢复、15 分钟或 1 小时。到时在下一次轮询恢复，并立刻去掉菜单栏斜杠。截止时间存在偏好里，重启后若已过期会直接恢复。设置页「记录状态」和菜单栏图标用同一状态 |
| 默认排除应用 | 已实现 | 首次启动预填钥匙串访问、系统「密码」、1Password、1Password 7、Bitwarden。可移除，也可从应用程序里再添加 |
| 忽略机密标记 | 已实现 | 默认开启。带 `org.nspasteboard.ConcealedType` 时不采集 |
| 临时标记 | 已实现 | 带 `org.nspasteboard.TransientType` 时不采集 |
| 安全输入 | 已实现 | 默认跳过。安全输入结束后 1 秒内的变化也跳过。「安全输入时仍记录」默认关闭 |
| 本机存储 | 已实现 | 历史在应用支持目录。日志和诊断 JSON 不含剪切板正文 |
| 不申请的权限 | 已实现 | 不申请输入监控、屏幕录制、完全磁盘访问。辅助功能只用于发送 ⌘V |

## 6. 保留与存储

数据在 `~/Library/Application Support/ClipboardAssistant/`：`history.db`（WAL、外键）、`payloads/<条目 id>/`、`thumbs/<条目 id>.jpg`。偏好在 `UserDefaults`，不含剪切板正文。

| 功能 | 状态 | 实现要点 |
|---|---|---|
| 条数 | 已实现 | 默认 500，可选 200 / 500 / 1000 / 不限制。超出时按最近使用时间删最旧的未置顶条目 |
| 天数 | 已实现 | 默认 30，可选 7 / 30 / 90 / 永久。按创建时间清理未置顶条目 |
| 图片容量 | 已实现 | 固定 200MB，设置里不能改。超出时删最久未使用的未置顶图片 |
| 置顶不参与淘汰 | 已实现 | 不参与条数、天数和图片容量 |
| 何时清理 | 已实现 | 每次成功插入后，以及启动时跑一次。改条数或天数后立刻再跑一次 |
| 删除顺序 | 已实现 | 先删数据库行，成功后再删负载和缩略图。清空后再 `VACUUM` |
| 查询失败 | 已实现 | `sqlite3_step` 失败会抛错。重新加载失败时记日志；这条路径会把界面列表清成空的，数据库本身不改 |
| 损坏库恢复 | 未做 | 设计里写了启动时做完整性检查、损坏后改名并新建空库。代码没有这一步 |
| 退出后仍在 | 已实现 | SQLite 持久化。进程被结束后历史、置顶和设置都还在 |

## 8. 不在 v1

这些能力需求和约定都明确排除，代码里也没有：

- 片段库、关键字触发、规则、按应用打标签、正则忽略
- 历史导入导出（诊断 JSON 不是历史导出）
- 云同步、iCloud、账号、团队共享
- OCR、翻译、AI 改写
- iOS / iPad 客户端
- App Store 沙盒版

数据库 `user_version` 固定为 1，给以后加表留了版本号，没有预建片段表或同步字段。
